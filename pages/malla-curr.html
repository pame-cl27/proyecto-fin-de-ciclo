Malla Curricular - Desarrollo de Sistemas e Información

Plan de estudios modular diseñado para dominar el desarrollo de software moderno y la integración de Inteligencia Artificial. Prepara a los estudiantes para construir arquitecturas robustas, automatizar procesos complejos e implementar modelos avanzados de análisis y visión por computadora, capacitando profesionales capaces de impulsar la innovación tecnológica en entornos digitales.

Módulo I
Desarrollo Web & Software
  • Programación en Python / JS
  • Interfaces Web Interactivas
  • Base de Datos Relacionales
  • Control de Versiones (Git)
Módulo II
Machine Learning & Visión
  • Fundamentos de ML
  • Análisis de Datos con Pandas
  • Visión por Computadora (YOLOv8)
  • Procesamiento de Imágenes
Módulo III
Deep Learning & NLP
  • Redes Neuronales Complejas
  • Procesamiento del Lenguaje Natural
  • Despliegue de Modelos Web
  • Proyecto de Innovación Técnica
Módulo IV
DevOps & Arquitectura Cloud
  • Despliegue en la Nube (AWS / Azure)
  • Contenedores con Docker
  • Integración Continua (CI/CD)
  • Monitoreo y Mantenimiento
Módulo V
Arquitectura de APIs & Datos
  • Desarrollo de APIs RESTful
  • Bases de Datos NoSQL (MongoDB)
  • Microservicios para IA
  • Optimización de Consultas
Módulo VI
Seguridad & Gestión Ágil
  • Ciberseguridad y Protección de Datos
  • Metodologías Ágiles (Scrum)
  • Ética en Inteligencia Artificial
  • Gestión de Proyectos Tecnológicos
